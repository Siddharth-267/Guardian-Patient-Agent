# Guardian Patient Agent

An AI-powered preliminary healthcare triage and risk-monitoring assistant built on **Salesforce Agentforce** and deployed via **Enhanced Chat (MIAW)** on GitHub Pages.

## Key Capabilities
- **Preliminary Risk Assessment:** Evaluates user-reported symptoms and health metrics for early diabetes and cardiovascular risk indicators.
- **Grounded Clinical Guidance:** Uses **Agentforce Data Library** and **Prompt Builder** to retrieve verified clinical reference guidelines while enforcing medical disclaimers.
- **Automated Session Routing:** Connects web users through **Omni-Channel Flows** with fallback queue escalation (`Guardian_Fallback_Queue`).

## Architecture & Tech Stack
- **AI & Orchestration:** Salesforce Agentforce, Atlas Reasoning Engine, Prompt Builder, Einstein Trust Layer
- **Data & Automation:** Salesforce Data Cloud, Agentforce Data Library, Omni-Channel Flow
- **Web Channel & Frontend:** Messaging for In-App and Web (MIAW), Embedded Service Deployment, HTML5/CSS3/JS (GitHub Pages)

> **Disclaimer:** This project is for educational and preliminary informational purposes only and does not provide medical diagnosis or replace professional clinical care.
